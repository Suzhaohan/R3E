# 本轮比赛演示版：范围与原方案的关系

本轮优先执行用户确认的“5 个对抗 design＋少量独立验证，五轮不变”。《设计依据_双机红蓝对抗方案.md》保留原文作为设计依据；本文仅记录历史版本；当前运行以[run06 最新指南](../../deepseek-run-06/source/运行指南.md)为准。

- 5 个对抗 design，每个两个原始错误版本；固定为 2 个练习家族、3 个晋升考试家族。
- 1 个额外寄存器 design 的两题用于防退步，3 个没参与演化的 design 共六题用于最终测试。总计 18 题。
- 五轮 R000–R004、A 固定策略、B 搜索与晋升、Memory OFF、每次 3 个候选、3 次重复、六种证据策略全部保留。
- A T0 → B T0 + 五轮 + T1 → A T1 → 冻结和比较；T0 不供演化读取。
- 原方案的完整 Strider-14 按用户指示改为 4 题子集，不再以完整公开基准名义报告。
- 保留至少改善两个设计等全部晋升门槛，允许零晋升；不通过放宽规则保证效果。
- 保留原始 RTL、依赖、测试台，以及实际/期望错误信息。真实模型不读取参考修复。
- 保留已修正的验证器：实际 token 修改量计数、按所属过程块检查局部范围、模块检查加载已冻结依赖。仍限一个局部块和 64 个修改 token。
- 保留连接失败的有限重试和成功响应缓存，TLS 证书验证开启。

旧全量运行方案已停用，其可执行源码与说明压缩归档以便追溯已有付费结果；当前源码只保留 demo18 运行清单和构建器。原始数据与已完成实验结果不删除。

边界：当前是同机两个隔离目录，不是已部署物理双机。策略搜索不更新模型权重。五轮跑通不等于效果必然提升；最终六题仅支撑小规模比赛演示，不足以声称广泛泛化或统计显著性。
