# 三道已有困难题，五轮定向经验学习

本版按用户“减少题目、保留失败把握更大的题”的要求，从原 10 道候选缩减为 **3 道考试题、2 个设计**。旧题单在 `cases-all-v1.jsonl`，旧方案与运行记录继续保留。

## 选择依据：核验本地原始记录

不再只依据低通过率汇总文档。`selection.json` 记录 9 份本机已有无经验校准原始记录、SHA256、模型与配置来源，以及每道移出题目的原因。校验代码确认记录没有注入记忆、没有 provider failure、不是未决结果，失败的最终状态为功能测试失败。

| 保留的原始题目 | 本地已有校准通过数 | 失败性质 |
| --- | --- | --- |
| Prob001，arithmetic 位序缺陷 | 1/3 | 两次运行各尝试三次后仍功能失败 |
| Prob015，timing 输出时序缺陷 | 1/3 | 两次运行各尝试三次后仍功能失败 |
| Prob015，state_machine 状态转换缺陷 | 1/3 | 两次运行各尝试三次后仍功能失败 |

题目、参考答案、规范与测试文件还须匹配历史运行绑定的 `low-pass-pilot-03/protocol.json` 文件哈希，防止把不同变体的失败成绩套到当前题上。三道题均为 ChipBench 原始缺陷，不含重建题。

移出 Prob003 原历史种子：较新的本地无经验校准已经 3/3 修好，不能继续只引用更早的 1/3。移出 Prob015 重建变异：较新校准为 2/3。Prob002、Prob023 的较新基线评估均为 3/3；Prob017 各变体也有较高修复率记录，且规范有矛盾，本次一并移出。

**这只是现有证据更强的困难候选，不是保证当前静态组修不了。** 校准只有三次观察，而且其运行声明模型为 `deepseek-flash`，新入口模型为 `deepseek-v4-flash`，不假定两者等价；反馈与预算也不同。筛选没有产生新的模型请求，最终仍应如实报告当前无经验组的真实成绩。

## 五轮如何学习

五轮不变，每轮给 Prob001、Prob015 各安排一个练习槽位，共 **10 个练习槽位**。Prob015 的定向机制同时覆盖两道考试题：金额状态转换与输出时序。每轮结束才提交经验，同轮不能提前使用刚产生的经验。

Red 获得干净设计、规范、目标机制、历史练习变异和实际修复结果，安排相关的新练习；遇到失败尝试更简单的相关题，成功后增加机制覆盖。考试缺陷 RTL、考试答案与考试成绩不提供给 Red。

练习题须保持接口、编译成功并在公开检查中表现为功能错误。与考试题或此前练习题规范化重复时拒绝，最多重出三次；其他无效提案记录失败，不补跑。Blue 只收到规范、当前缺陷代码和同设计最近最多四条成功练习经验（最多 8192 tokens）。只有实际通过练习测试的修复补丁能入库。

## 最后考试

三道固定原题，在静态 B₀、最终经验 B₅ 下各测两次，共 **12 次考试修复**。两组同模型、同题、同预算、配对种子，顺序交替。静态组始终空经验；考试请求相互独立，考试结果不进入学习、不用于选最佳状态。完整文件提交，最多一次格式纠正；功能失败不追加修复。

本次目标仍是检验“静态低、经验高”，不保证该差异，更不通过事后删题、补跑或隐藏失败制造差异。正确答案留在本地评分侧，按冻结参考测试判分；报告包括每题、两组、错误类别、格式纠正和经验送达，以及练习/考试修改位置重叠。

## 离线验证

在项目根目录执行：

```bash
bash hard-case-five-round-01/run.sh check
.venv/bin/python -m pytest -q hard-case-five-round-01/tests
bash hard-case-five-round-01/run.sh smoke --run-dir hard-case-five-round-01/smoke-new
```

默认冻结方案为 **`plan-focused-v2/`**，只允许使用本版题单和代码。旧 `plan-final/`、`plan-v*/` 是之前版本，不用于本次启动。修改题目、代码或环境必须新建方案：`freeze --plan-dir 新目录`，后续命令显式使用同一个 `--plan-dir`。

`check` 核验已有原始证据，并实际仿真三道题的正确实现和缺陷实现，不调用模型。`smoke` 使用固定假回答与真实仿真，只验证流程，不代表真实模型成绩。

## 实际请求预算与启动

正常无重出或格式纠正时最多 **32 次**：10 次 Red + 10 次练习修复 + 12 次最终考试。包括所有预留纠正与重出的硬上限为 **84 次**，比上一版 260 次减少 176 次。金额硬上限沿用此前取消的设置，仍有有限请求、上下文、输出与返回用量检查。

本次修改不启动真实实验。后续执行以下命令才会产生付费请求：

```bash

  --env-file /绝对路径/凭据文件 \
  --run-dir hard-case-five-round-01/real-focused-v2
```
