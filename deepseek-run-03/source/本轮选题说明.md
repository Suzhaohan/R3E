# 本轮选题：5 个对抗 design，18 道原始题

本轮按比赛演示的需要固定规模。design 指一个原始电路设计，同一电路的两个错误版本是两道题，不是两种 design。

| 电路 | 用途 | 两个案例编号 | 错误类型 |
|---|---|---|---|
| 三人表决电路 | 晋升考试 | `assignment4v:JG3_1` / `assignment4v:JG3_10` | 输出真值错误；分支匹配条件错误 |
| 七段数码管译码器 | 晋升考试 | `assignment4v:decl7s_1` / `assignment4v:decl7s_2` | 编码错误并缺少分支；缺少分支；原始资源只有这两个版本 |
| 带使能的三八译码器 | 晋升考试 | `assignment4v:decoder3e_4` / `assignment4v:decoder3e_5` | 使能极性颠倒；输出编码位宽错误 |
| 全加器 | 练习 | `assignment4v:fa_behavioral_1` / `assignment4v:fa_behavioral_2` | 异或误写成或；求和表达式错误，涉及取反与运算符 |
| 二选一选择器 | 练习 | `assignment4v:mux21_1` / `assignment4v:mux21_4` | 选择条件颠倒；遗漏 else 导致赋值不完整 |
| 24 位寄存器 | 防退步检查 | `assignment4v:latch24_1` / `assignment4v:latch24_2` | 写入常数而非输入；时钟触发条件错误 |
| 六位十进制计数器 | 最终独立测试 | `assignment4v:counter6bit_22` / `assignment4v:counter6bit_11` | 进位边界错误；复位敏感条件错误 |
| 仲裁状态机 | 最终独立测试（Strider 子集） | `strider:fsm_full_1` / `strider:fsm_full_4` | 遗漏授权分支；阻塞与非阻塞赋值混淆 |
| 四选一选择器 | 最终独立测试（Strider 子集） | `strider:mux_4_1_1` / `strider:mux_4_1_3` | 选择分支重复或错误；输出位宽错误 |

共 **5 个对抗电路、1 个防退步电路、3 个独立测试电路**，每种两个版本，共 **18 题**。其中 4 道练习题、6 道晋升考试题、2 道防退步题、6 道最终测试题。

电路用途在运行前固定，同一家族不跨练习、晋升考试和最终测试。晋升考试覆盖 3 个不同设计，可以满足至少改善 2 个设计的门槛；不降低门槛来制造晋升。

五轮 R000–R004 保持不变。每轮 Red 最多提出 4 个新错误，经过真实验证再决定是否入选。新生成题属于对抗流程，另行记录，不把它们冒充原始题。每次修复三个候选、三次重复、六种证据策略、Memory OFF 保持不变。

最终测试 6 题包括：计数器 2 题、状态机 2 题、四选一选择器 2 题。其中后四题来自 Strider，只能报告为 Strider 4 题子集。A/B 在 T0/T1 使用完全相同的固定测试题。

本轮不接入 RS、SDRAM、SHA3 等较重案例，不自动扩充到其他家族。原始数据仍保留；当前运行清单与构建器只包含这 18 题。

选题根据错误机制和验证可用性预先确定，不按真实模型成功率选题。七段译码器只有两个原始版本且错误重叠，保留此限制。将参考答案送入离线验证器仅用于确认题目存在规则允许的正确答案，不是模型效果测试，也不把答案交给真实模型。

演示时先展示一个完整对抗过程，再按 design 展示结果，包括失败、未晋升和退步。5 个对抗 design 提供比单个设计更丰富的证据，但不能据此声称适用于所有电路。
