## 使用与限制

已用原项目现有 Python 环境通过实际启动脚本执行 `--no-serve`，成功生成可直接复用的完整记录：`/tmp/r3e-arena-demo-v3-ready/demo.json`。启动页面：

```bash
bash m3_demo_v3/competition/scripts/run_arena_demo.sh \
  --evidence /tmp/r3e-arena-demo-v3-ready/demo.json
```

临时目录可能被系统清理；丢失时使用不带 `--evidence` 的启动命令重新生成。

启动与回放见 [开始演示.md](开始演示.md)。每次新运行使用新空目录，拒绝覆盖已有证据。完整运行目录含 Core 绑定的绝对路径，建议在原生成位置回放；跨机器搬迁要在目标机器重新生成工程演示。正式双机 Observer 使用已经导出的 frozen comparison，不依赖离线 demo 目录搬迁。

尚未执行真实模型 API 或真实两台机器上的实验，也没有冻结正式 Strider-14 / Red-Heldout 成绩。要完成比赛方案中的真实能力对比，仍需模型配置、调用预算、两个部署环境、干净源码提交以及真实评估记录。
