# 03 结果复盘与补救方案

本报告仅分析现有账本，没有新增模型调用，不修改原始结果。

## 已经成立的结果

五轮完成，第一轮两条经验通过晋升及防退化验证，之后没有新增激活经验。最终五题的十五次配对中，空记忆与第五轮经验组均为 15/15；两个 Prob003 变体的补充检查也均通过。因此最终考核没有证明经验组优于静态组。

第一条晋升经验验证时，其对照经验池为空。逐题结果如下，来自 `qualification.jsonl` 第一条记录：

| 晋升验证题 | 空记忆 | 加入第一条候选经验 |
| --- | ---: | ---: |
| `chipbench:arithmetic:Prob001_continuous_input_sequence_detect` | 1/3 | 2/3 |
| `chipbench:state_machine:Prob015_vending_machine2` | 0/3 | 3/3 |
| `reconstructed:Prob015:documented_red` | 2/3 | 2/3 |

这些题属于已练习的题。该结果能支持练习题上的配对改善，不能当作独立最终考核优势，也不能把后续“已有经验 vs 新增经验”的验证结果都称为空记忆对比。

## 设计问题

难度校准测的是练习题，未检验最终考核的成功率是否饱和。Prob017/Prob023 的历史记录已经很容易，两个 Prob003 新变体只有仿真资格检查而无当前 Blue 难度证据。实际最终基线 15/15，使成功率提升没有空间。额外扩大候选数量和重复练习未解决这个前提问题。

## 不增加模型调用的处理

1. 保留当前原始账本、候选补丁、全部快照和最终结果，完整报告晋升验证的局部收益与最终考核的零增益。
2. 已有校准、相同配置下的空记忆分支和共同首试均可作为匹配条件一致时的缓存；不同题、种子、测试、预算或已有经验池不能混用。
3. 不将看过的晋升题改名为新的独立考试题，不通过剔除平局或退化配对重算一个正结果。

## 如确需补充最终效果证据

不重跑五轮，不追加学习，不改变原有修复预算或晋升门槛。冻结当前第五轮经验，准备两个未参与学习及晋升验证的目标机制新变体：优先来自已有改善证据对应的 Prob015 状态机和 Prob001 位序机制。先离线检查正常实现通过、缺陷失败、变体与本次训练记录不重复，并冻结题单、种子、停止条件和判断口径，再单独授权一小批配对测量。

每个变体三次重复，每个分支最多三次修复，共享首试失败；每对最多五个模型请求，两个变体最多三十次。无额外校准、无 Red 在线生成、无追加三次学习、无经验更新、无四候选验证、无重新评测五个快照。输出额度保持原实验设置，不通过降低静态组预算制造差异。

必须在请求前执行用户批准的新增 token/费用硬上限；配对所需预算不足则整对不启动。全部基线仍通过时如实报告饱和并停止，不扩大题池收费搜到想要的结果。此补充实验仍可能持平或退化，不能预先保证优势。本报告不授权或启动任何付费请求。
