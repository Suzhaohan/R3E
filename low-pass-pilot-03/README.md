# 低通过率 RTL 五轮实验：Prob003 增强与考核精简版

保留 03 的五轮练习、经验晋升、防退化检查和最终考核。未启动付费请求。

## 题目分配

- 练习及晋升仍为五题：Prob015 timing/state_machine、Prob015 重建历史缺陷、Prob001，以及交接包的 Prob003 历史缺陷。
- 正式 Prob003 历史缺陷替换原重建输入，两者代码相同，不重复计为新题。使用交接包的新时序规范和公开测试，因此不与 02 的成绩直接合并。
- 原考核精简为三题：Prob023、Prob017 timing 和 Prob002。新增两个 Prob003 变体后共五题，保持三次配对重复。
- 增加两个最终评估变体：`eval_match_branch` 和 `eval_miss_branch`，各重复三次，五轮收集结束后才修复评估。
- `reset_control` 仅用于离线验收，不进入学习、晋升或最终成功率。

两个新变体来自已练习的 Prob003 设计。它们测量同设计的新缺陷修复，不代表跨设计泛化。报告将它们与原有考核分开；主考核仍为 `original_exam`。

## 根据 02 的记录精简考核

没有新增模型测量或试跑。`selection.json` 保存选择依据及 02 晋升账本的 SHA256。基线按轮次、题目、种子去重，排除共享基线被不同候选重复统计；跨轮记录仍非独立电路样本。

Prob017 assignment 的有效基线为 15/15 通过，arithmetic 为 11/11 通过（另有一次无法判定），两者成功最多需要两次修复，且属于同一分频器设计。因此从本次考核移除，原数据和历史结果保留。Prob017 timing 为 12/12 通过，其中一次用了三次修复，保留作该设计的代表题；Prob023 为 10/10 有效基线通过（另有两次无法判定），保留作不同设计的代表题。它们用于观察保持能力，不声称目前困难。

Prob002 在 02 最终评分中通过 2/3、失败 1/3，继续考核；Prob001 在当时评分中失败 3/3，继续留在练习与晋升。Prob003 历史种子及新变体用于组边界机制训练与评估；两个新变体未经真实模型测量，不能预先声称困难或保证晋升收益。

精简后原考核每个快照为 9 个配对，Prob003 为 6 个，共 15 个；此前为 21 个。缺陷数减少两题，但仍保留三种原考核设计。成功率仅适用于提前选定的题单，不能与旧七题的总分直接解释为能力变化。

## 材料与信息边界

`materials/prob003/` 保留学长交付的 RTL、规范、许可证、原公开测试、补充 evaluator、交接说明和哈希清单。导入时已验证原包清单；启动前再次检查所用原文件。部分 RTL 导入时仅补文件末尾换行，校验明确允许这一项存储差异。代码快照、分词器和独立三轮启动器不用于本五轮流程，模型及修复预算沿用 03。

`tb_visible.sv` 将公开测试的全部 256 组输入、输出稳定性和异步复位刺激转换为现有仿真器所需的 CSV 轨迹。原 `W_bug`、`W_preserve` 保留，离线检查分别重放全部缺陷和正常实现，确认测试链路。

保留题不进入练习、晋升、难度校准或经验库。Red 只接收练习载体；裁判在准入时拒绝保留缺陷的规范化重复，不向模型提供被保留的代码或标签。其他训练缺陷仍可能修改相同位置，事后报告记录 Red 的修改位置。

补充 evaluator 只用于离线资格检查及五轮收集和最终公开评分结束后的评估，不参与 Blue 的反馈、经验更新或晋升。Prob003 候选 RTL 保存于运行目录的 `prob003-artifacts/`，补充评估无需再请求模型。

## 运行

在仓库根目录执行：

```bash
bash low-pass-pilot-03/run.sh check
bash low-pass-pilot-03/run.sh smoke --state-dir low-pass-pilot-03/smoke-focused-state
```

这两个命令禁止网络连接、不调用模型。已有 `smoke-state` 和 `smoke-handoff-state` 是历史模拟结果，不能用于验证本次选题变更；若以后需要模拟，请使用新的状态目录。

真实运行建议在 tmux 中启动。下面的 `start` 会产生 API 费用；没有环境密钥时，会在交互终端安全提示输入。

```bash
bash low-pass-pilot-03/run.sh start --state-dir low-pass-pilot-03/real-focused-state
bash low-pass-pilot-03/run.sh status --state-dir low-pass-pilot-03/real-focused-state
```

新状态目录首次启动时必须未被其他实验使用。配置、材料、源码、模型均绑定；相同目录再次启动仅续跑同一次实验，不能混入旧结果。

先校准五个练习输入：每题三次、每次最多三次修复，空记忆失败至少三次且无无法判定结果才进入五轮。前两轮后仍无有效经验会停止，不继续空跑或调用最终题。

维持每轮五个固定练习加两个 Red 提案、最多四个候选经验、三次配对验证及三道防退化检查。精简考核减少最终评估的配对槽位，但实际调用数取决于提前成功和结果复用；1300 次调用硬上限不变，包含失败调用；不足时停止，不自动扩容。晋升或成功率提升不能提前保证。

## 查看结果

- `calibration.json`：练习难度校准。
- `rounds.jsonl`、`qualification.jsonl`：实际晋升、经验送达及拒绝原因。
- `comparison.json`：公开测试结果，`snapshots[*].groups.original_exam` 为精简后三题考核，`prob003_seen_design` 为两个新变体；总分仅作混合样本描述。
- `prob003_audit.json`：补充 evaluator 结果、经过补充检查的 Prob003 配对统计、保留题进入学习的检查和训练修改位置。
- `calls.jsonl`：真实请求及 token 账本；先检查 `binding.json` 的 `mode` 区分真实与模拟结果。

最终报告自动执行离线补充审计。完成后也可以重复执行，不调用模型：

```bash
bash low-pass-pilot-03/run.sh audit --state-dir low-pass-pilot-03/real-focused-state
```

公开测试通过、补充测试通过和完整功能正确性是不同层次；这些有限检查不能证明完整正确性。原考核已在 02 中观察过，新版属于开发实验，不能称为完全未接触的基准。补充和公开测试来自同一作者，不声称作者独立。
