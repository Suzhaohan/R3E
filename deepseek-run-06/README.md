从项目目录执行：`bash deepseek-run-06/run.sh start`。
网页：<http://127.0.0.1:8086>，沿用 run03 界面。

保留原来的五轮、每轮最多五个候选策略、三次配对测试和最终六道评分题。

只增加两道独立防退化题：译码、时序计数。加上原来的两道锁存器题，共四道。加法器和多路选择继续使用原流程已有的练习检查。最终评分题不拿来提前训练，也不改变。

A 使用固定策略和空记忆。B 仅积累当前实验中的修复经验，成功与失败都保存；前一轮已完成的经验经过小检查后供下一轮使用。每轮内记忆固定，最终评测不再更新记忆。

经验更新检查只跑记忆实际影响到的代表题一次；策略晋升保留原有三次配对规则。不增加最终16题检查，不导入旧版本经验，不生成额外开发题预览。

相同目录重新执行 start 是断点续跑，继续同一次实验。独立新实验必须使用新状态目录并重新初始化，不能复用已完成实验的状态目录。
