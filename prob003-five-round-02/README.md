# Prob003 五轮实验：允许撞考试题后重出，提高输出上限

本目录是 `prob003-five-round-01` 的新版。旧目录、原冻结方案及真实运行证据保持原样。
本次只修改用户指定的两项行为，不导入旧运行的学习经验，不更换记忆筛选规则。

## 修改后的行为

- 每轮出题若与两个保留考试题之一重复，丢弃该题并重新出题，仍属于同一轮。
- 每轮初次出题之外，最多重出 3 次；连续 4 次撞题则记录拒绝并进入下一轮。
- 重出时只提供模型自己刚才生成的修改，要求不要重复；不提供保留题列表、答案或考试测试。
- 只有最终获准的题进入修复；撞题不更新修复经验。其他拒绝、历史种子重复、空回答或接口错误不自动重试。
- 恢复 pilot-02/03 的上限：出题 **32,768 token**；经验组、无经验组及最终考试修复均为 **65,536 token**。
- 所有尝试均保存并计费、计入总请求数。五轮基础 39 次，加上最多 15 次重出，总上限 **54 次**。未使用的重出额度不用于其他补跑。

五轮、每轮两组各一次修复、两个保留题在六个经验状态上各测两次、学习规则、模型和温度均延续 01。金额硬上限继续按之前授权取消。
按交接包历史费率、全部上下文和输出额度估计的条件性上界为 ¥31.890472；不是实际费用或当前报价。

## 运行入口

已生成新版冻结方案 `plan-v3/`，默认使用该方案。只读检查、不调用模型：

```bash
bash prob003-five-round-02/run.sh check
```

真实运行必须使用新目录，例如：

```bash
bash prob003-five-round-02/start.sh \
  --run-dir prob003-five-round-02/real-v1 --port 8095
```

若指定端口被其他运行或服务占用，程序自动尝试后续端口（最多检查 20 个），请按终端实际打印的地址打开页面或转发端口。

启动后在终端粘贴 DeepSeek API 密钥并按回车，输入不会显示。密钥仅通过内存中的文件描述符传给实验进程，不写入磁盘、命令行参数或日志；无需准备密钥文件。也兼容原有的 `--env-file` 参数。

本次修改没有启动付费请求，不恢复或覆盖 01 的运行。上述入口包含网页，并在收集结束后生成离线报告和审计。

## 验证与记录

`smoke-v3/` 是固定回答的离线验收，第一轮故意撞考试题，再成功重出；五轮及最后考试共 40 次模拟请求，真实模型调用为零。

```bash
.venv/bin/python -m pytest -q prob003-five-round-02/tests
```

重出记录位于 `collection/generation_attempts.jsonl`；每次完整请求、响应和候选位于各轮的 `red/`、`red_retry_1/` 等目录。`slots.jsonl` 记录每轮最终题目、全部出题尝试和实际调用数。

`handoff/` 保留原交接材料。`source/` 中只改了调度与出题请求两个文件，清单在 `protocol_changes.json`；其他 55 个冻结源码文件仍与交接包一致。新版方案同时绑定修改后的源码、入口、预算和每次请求上限。
